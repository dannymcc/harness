Preview

The command that starts this project's app so its pages can be rendered. Set it and an engineer changing templates or stylesheets opens the routes in a real browser at phone and desktop widths, saves screenshots and reads back what the CSS cannot tell them — a page wider than the viewport, elements past the right edge, console errors. Leave it empty if the project has no UI: nothing is rendered and nobody is asked to. It must leave the app answering on http://127.0.0.1:8000 with demo data and no login in the way.
